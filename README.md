💬 ChatGPT Clone (Frontend Only)
This project is a frontend-only ChatGPT clone built using HTML, CSS, and JavaScript. It simulates a basic chatbot interface where users can type messages and receive predefined responses.

✨ Features:
Clean and responsive UI: Designed with HTML and styled using modern CSS for a user-friendly interface.

Interactive chat interface: Users can type queries and receive instant responses from the bot.

Predefined bot replies: The bot responds based on a set of hardcoded inputs, mimicking real chatbot behavior.

Typing animation effect: Adds a realistic typing feel when the bot responds.

Mobile-friendly layout: Fully responsive design that works on various screen sizes.

🛠 Technologies Used:
HTML – For structuring the webpage.

CSS – For styling the user interface.

JavaScript – For handling user interactions and displaying chatbot responses dynamically.

🧠 Chat Logic:
The bot recognizes and replies to specific phrases such as:

"hello" → "Hi there! How can I help you today?"

"bye" → "Goodbye! Have a great day!"

"write hello world program in c++" → Displays the basic C++ Hello World code.

If the input doesn’t match any known phrase, the bot replies with:
"Sorry, I didn't understand that. Can you rephrase?"
